# Archived flat chapter drafts

This directory preserves the exact flat-path files that were present before the
canonical folder-based chapter structure was completed. Some are earlier drafts
and some carried later alignment edits; none is now an independent source of
truth. They remain here so that pre-existing and uncommitted work is not
silently discarded. The canonical Chapter 1–8 paths are listed in
`docs/chapters/README.md` and `docs/thesis_assembly_order.md`.

The archive contains all eight former flat chapter files. In particular,
Chapters 7 and 8 were recovered from the tracked pre-migration versions so that
their later folder-based revisions do not erase the earlier drafts.
