28 Experiments and Evaluation
Experimental Setup
The current phase of research uses a new hybrid validation-based self-correction system
which employs both neural and rule-based reasoning methods to create explainable persona
alignment for its research requirements. The research phase uses elements from three recent
areas of progress which include multi-agent LLM frameworks, retrieval-augmented generation (RAG) system, and neuro-symbolic artificial intelligence approaches [39, 40].
The system establishes four interactive agents through its LangGraph implementation,
which uses closed feedback loops to assign each agent its designated work functions. The
system processes an input movie plot together with a target persona to generate a validated
Bengali movie review that matches the required persona presentation style. The overall
workflow consists of three core implementation steps:
